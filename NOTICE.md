# Artifact provenance

OpenCGM-StateEvent is by Stephane Fourdrinier. The independent community
reconstruction is described in the [pinned model card](https://huggingface.co/sfourdrinier/opencgm-stateevent/blob/6c53e572c2dafcb0b030f2e1aa4f3a2a8d7f7ca3/README.md)
and [source repository](https://github.com/sfourdrinier/opencgm/tree/bcf8ac2dfca00f8fb3c7728fb2a3a2bd2803bebf).

The encoder is labeled **CC-BY-NC-4.0** by its maintainer. The corresponding source
is **Apache-2.0**. `demo-lock.json` pins the encoder, model card, license/notice files,
and relevant source files. These public artifacts are downloaded on demand; the
repository does not redistribute model weights or bundled downstream probe heads.

The original method is described by Zechen Li et al., *GlucoFM: A Dual-Stream
Foundation Model for Continuous Glucose Monitoring*,
[arXiv:2605.30865v2](https://arxiv.org/abs/2605.30865v2). This project evaluates the
community artifact, not a Google checkpoint. Its historical pretraining claims
remain attributed to the maintainer.
